# 👁️ EyeGuard – Smart Screen-Time & Eye Health Monitoring App

EyeGuard is a production-ready mobile application designed to help parents monitor and manage their children's screen usage while promoting healthy eye habits.

The app combines screen-time tracking, AI-based eye strain prediction, and gamified wellness features to encourage better digital behavior among children.

---

## 🚀 Key Features

### 📊 Screen-Time Monitoring
- Tracks app usage and screen exposure duration
- Provides daily, weekly, and monthly analytics
- Detects excessive continuous usage

### ⏰ 20-20-20 Eye Care System
- Smart reminders every 20 minutes
- Animated eye relaxation prompts
- Eye exercise suggestions

### 🌳 Outdoor Activity Tracking
- GPS-based outdoor detection
- Step tracking integration
- Daily goals and streak rewards

### 👨‍👩‍👧 Parent Dashboard
- Multi-child monitoring support
- Detailed usage reports
- Alerts for unhealthy screen habits
- Personalized recommendations

### 🎮 Gamification
- Reward points and badges
- Daily challenges (drawing, coloring, physical activity)
- Habit-building streak system

### 🔔 Smart Notifications
- Break alerts
- Activity reminders
- Health warnings for prolonged usage

---

## 🧠 Advanced Features
